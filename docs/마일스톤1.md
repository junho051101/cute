# 마일스톤 1 (제안): 초원 챕터 핵심 루프

기획자가 "처음 부분만 구현"을 요청해서 잡은 범위 제안이다. 범위는 시작 전에 기획자와 확인한다.

## 목표
초원 챕터 하나를 처음부터 끝까지 한 판으로 플레이할 수 있고, 로그라이크 핵심(귀환/상승 선택, 죽으면 전부 초기화)이 동작하는 것.

## 포함 (제안)
- 초원 챕터: 5스테이지 x 5라운드, 마지막에 보스방
- 자동 전투: 체력, 공격력, 방어력, 공격 속도 4개 스탯을 우선 구현
- 직업 3개(전사, 궁수, 도적)가 시작 때 랜덤으로 정해지고 죽을 때까지 유지
- 고양이 처치 시 해바라기씨와 경험치, 레벨업 시 모든 스탯 자동 상승
- 스테이지 클리어 후 "귀환/상승" 선택, 보스방 앞 "도전/귀환" 선택
- 죽으면 장비, 돈, 레벨이 전부 초기화되고 새 직업으로 다시 시작
- 장비와 희귀도의 최소 버전(무기, 방패 등 소수), 보물 방과 이벤트 1~2종(이벤트 샘플인 "망 봐 주며 쉬자" 포함)
- 마을 화면: 캐릭터 직접 이동, 여관(체력 회복), 장비 강화 건물, 직업별 업그레이드 건물의 최소 버전
- 모든 수치는 임시값으로 `data/`에 분리

## 제외 (나중 마일스톤)
- 균열 이벤트, 동료 시스템, 고양이의 영혼(아이템 창과 스킬)
- 마법사 직업과 마탑
- 정신력, 육감, 회피, 행운, 치명타 스탯(구조만 열어 두고 값은 비워 둠)
- 숲, 강가, 눈 덮인 고원 챕터
- 피로/공포 상태이상

## 완료 기준
1. 한 판을 처음부터 끝까지 플레이해서 보스에 도전할 수 있다.
2. 죽었을 때 모든 것이 초기화되고 새 직업으로 시작된다.
3. 귀환하면 레벨은 유지되고, 마을에서 해바라기씨로 장비 강화와 체력 회복을 할 수 있다.
4. 수치와 텍스트를 코드 수정 없이 `data/`에서 바꿀 수 있다.
5. 문서의 "폐기된 설정"이 구현에 들어가지 않았다.
