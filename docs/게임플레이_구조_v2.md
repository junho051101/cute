# 게임플레이 구조 v2 (로그라이크 개정판)

이 문서는 기획자가 대화에서 직접 확정한 게임 구조를 정리한 것이다.
"확정"만 사실로 취급하고, "제안"과 "미결정"은 확인 전까지 교체 가능한 임시값으로만 다룬다.
이전 문서 `밸런스_장비_설계_v1.md`는 장비 영구 보존과 고양이 드롭을 전제로 해서 이 문서로 대체되었다.

## 확정

### 기본
- 전투는 자동 전투
- 지하철 같은 곳에서 가볍게 즐기는 구성(짧은 호흡, 한 손 조작, 모바일 중심)
- 로그라이크: 죽으면 장비, 돈, 레벨이 모두 초기화되고 남는 것은 플레이어의 지식뿐 (영구 성장 요소 없음)
- 캐릭터의 유지력(체력 회복 등)은 약하게 설계

### 구조
- 한 챕터(지역) = 5스테이지, 한 스테이지 = 5라운드
- 한 스테이지는 약 1~2분, 스테이지 도중에는 돌아갈 수 없음
- 스테이지를 깰 때마다 "마을로 귀환" 또는 "위층으로 올라가기"를 선택
- 5스테이지를 지나면 보스방 앞에 도착하고, "도전" 또는 "마을로 돌아가기"를 선택
- 마을에서 출발할 때는 항상 첫 스테이지부터 시작
- 보스에게 지면 전부 잃고, 이기면 챕터 클리어

### 성장·경제
- 마을로 귀환하면 돈으로 장비를 업그레이드하거나 강화
- 귀환해도 레벨은 유지됨 (죽으면 초기화)
- 고양이는 돈을 떨구고, 돈은 해바라기씨 (고양이가 가진 이유는 설정하지 않음)
- 장비는 스테이지 중 확률로 뜨는 보물 방이나 이벤트에서 얻음. 마을의 장비 상점에서 해바라기씨로 살 수도 있음 (판매 목록과 가격은 미결정)
- 이벤트는 스테이지당 평균 2회 발생하고, 위치(라운드)와 횟수는 판마다 랜덤
- 이벤트 종류는 계속 추가할 예정
- 이벤트가 뜨면 어떤 이벤트인지 먼저 보여 주고, 할지 말지를 플레이어가 선택함
- 이벤트에는 좋은 것, 나쁜 것이 섞여 있고, 위험이 클수록 좋은 장비(높은 희귀도)가 걸려 있음. 플레이어가 잘 판단해서 선택하는 것이 핵심
- 장비는 영역에 흩어진 물건이며, 선배 햄스터의 유품이라는 설정은 쓰지 않음
- 장비에는 희귀도가 있음
- 장비 슬롯은 6칸: 무기, 헬멧, 갑옷, 신발, 장신구 2개 (방패 슬롯 없음)
- "고양이의 영혼": 고양이를 잡으면 가끔 떨어지는 아이템. 별도의 아이템 창이 있고, 유용한 액티브 스킬을 주고, 스킬은 자동으로 발동됨
- 영혼의 장착 칸은 처음에는 한 칸이고, 특정 레벨마다 한 칸씩 늘어남 (어느 레벨에 늘어나는지는 미결정)

### 의도한 플레이 감각
- 스테이지 1~5를 반복해서 돌며(뺑뺑이) 장비와 돈을 모으고, 마을에서 강화한 뒤 보스에 도전
- 지면 다 잃으니 조심스럽게 파밍하고 집중하게 되는 긴장감

## 스탯 (확정 목록)
- 기본: 체력(HP), 공격력(ATK), 방어력(DEF), 공격 속도(SPD), 정신력, 육감
- 추가: 회피, 행운(희귀도/드랍/씨앗 획득에 영향), 치명타(확률/피해)
- 체력 회복은 스탯으로 두지 않음 (유지력을 약하게 한다는 확정 설정과 일치)
- 정신력: 피로와 공포에 저항하는 스탯이며, 체력이 낮을 때 확률적으로 살아남게 해줌 (피로/공포 같은 상태이상이 존재함)
- 육감: 일정 수치 이상이 되면 함정이나 부정적인 이벤트를 감지함 (지력은 삭제됨). 감지 수치 기준은 미결정
  - 육감이 기준 수치보다 낮으면 이벤트가 좋은지 나쁜지 구별할 수 없음
  - 기준 이상이면 부정적인 이벤트에서 "뭔가 부정적인 느낌이 든다"는 모호한 힌트가 나옴 (구체적인 내용은 알려 주지 않음)
- 경험치는 고양이를 쓰러뜨릴 때 얻음
- 레벨업할 때마다 모든 스탯이 조금씩 자동으로 오름 (플레이어가 분배하지 않음). 직업별 오르는 양의 차이는 미결정
- 스탯의 수치, 성장 곡선, 장비/레벨/영혼이 각 스탯에 기여하는 방식은 미결정

## 직업 (확정 일부)
- 시작할 때 직업이 랜덤으로 결정됨
- 직업 후보로 전사, 궁수, 도적이 언급됨 (직업의 최종 목록과 개수는 미결정)
- 현재 직업은 전사, 궁수, 도적 3개로 시작
- 마법사는 나중에 추가할 예정 (가끔 마법사로 태어나고, 마탑에서 돈(해바라기씨)을 내고 마법을 배움). 지금 구현 범위에는 넣지 않음
- 직업별 스탯 성향: 전사는 체력과 방어력이 높고, 궁수는 공격 속도와 공격력("힘"은 공격력을 뜻함)이 높고, 도적은 치명타와 스피드(공격 속도)가 높음 (공격력에서 스피드로 변경됨)
- 직업마다 시작 무기가 다름: 전사는 검, 궁수는 활, 도적은 단검
- 직업별 고유 능력은 미결정
- 죽고 새로 시작할 때마다 직업이 새로 정해지고, 한 번 정해지면 죽을 때까지 유지됨 (마을 귀환 때는 바뀌지 않음)

## 동료·상점 (기획자 제시)
- 탐험을 다니다 동료를 구할 수 있음
- 상점 근처에서도 동료를 구할 수 있음
- 동료는 확률적으로 영입할 수 있고, 동료가 되면 자동으로 싸우며 플레이어는 동료의 장비 등을 설정할 수 있음 (직접 조작은 하지 않음)
- 동료가 죽으면 사라짐
- 완전한 싱글 플레이. 플레이어가 맡는 건 주인공 1명뿐이고, 동료는 AI 햄스터로 전투 화면에서 주인공 옆에 서서 함께 싸움. 협동·대전·랭킹 같은 멀티 요소는 없음
- 동료 직업은 전사/궁수/도적 중 랜덤이고, 영입 전에 직업과 레벨을 볼 수 있음
- 고양이를 쓰러뜨리면 동료도 경험치를 얻어 스스로 레벨업함
- 동료 장비는 주인공과 같은 6칸이고, 고양이의 영혼도 장착할 수 있음
- 동료가 죽으면 동료는 사라지지만, 끼고 있던 장비는 주인공 가방으로 돌아옴
- 귀환하면 동료도 유지되고, 주인공이 죽으면 동료도 전부 잃음
- 영입한 동료는 배신하지 않음 (배신은 이벤트에서 만나는 다른 탐색자만)
- 동료가 되는 존재는 같은 탐색자 햄스터이고, 고양이는 동료가 될 수 없음
- 상점(마을) 화면에는 가끔 햄스터가 돌아다니고, 이 햄스터를 탭하면 확률적으로 동료로 영입할 수 있음
- 상점 화면에서는 캐릭터를 직접 움직이지 않고, 건물을 탭해서 들어감 (세로 화면). 가상 조이스틱 이동은 폐기
- 마을 건물: 장비 상점, 강화 상점, 직업별 건물 3개(전사/궁수/도적), 여관, 마탑(추후). 마을 가운데에 분수대
- 상점에는 직업별 업그레이드 건물이 있고, 거기서 돈(해바라기씨)을 내고 신체 업그레이드를 할 수 있음
- 신체 업그레이드도 죽으면 초기화됨 (영구 성장 요소 없음)
- 장비 강화는 별도의 "장비 강화 건물"에서 함 (직업별 건물은 신체 업그레이드 담당)
- 마을의 여관에서 해바라기씨를 내면 체력이 회복됨 (귀환만으로는 회복되지 않음)
- 동료 수 제한은 미결정

## 이벤트 예시 (기획자 제시, 이벤트 설계의 기준 샘플)
**"서로 망을 봐 주며 쉬자"는 제안**
- 어떤 햄스터가 서로 번갈아 망을 보며 휴식하자고 제안하고, 플레이어는 받아들일지 선택
- 받아들이면 50% 확률로 상대가 배신하고, 50%는 정말 잠만 자서 회복
- 의심해서 자지 않고 맞붙으면 싸워서 이기면 약탈할 수도 있음
- 이 예시에서 읽히는 구조: 이벤트는 제안 + 선택지(예/아니오 이상의 선택 가능)이고, 결과는 확률로 갈리며, 선택에 따라 이득과 위험이 달라짐
- 등장하는 "다른 햄스터"는 같은 탐색자들이며, 각자 스스로 자원해 떠났고 가끔 배신하고 더 좋은 장비로 더 깊이 가려는 이도 있음

**"균열이 열렸다" 이벤트 (기획자 제시)**
- 가끔 균열이 열리고, 들어갈지 말지를 플레이어가 선택
- 균열 안에서는 훨씬 강한 고양이가 등장하는 대신, 클리어하면 일반 스테이지보다 강한 보상(장비·고양이의 영혼)을 얻음 (별도의 몬스터는 없음)
- 균열의 정체(왜 열리는지, 세계에서 어떻게 받아들여지는지)는 아직 미결정

## 폐기
- 햄스터가 쓰러져도 장비 유지
- 5분마다 열리는 이벤트로 장비 획득
- 고양이를 쓰러뜨려 유품을 얻는 방식 (출처 문제는 미결정 참고)
- 영구적인 레벨/장비 성장 설계

## 흐름 (이해한 대로의 요약)
```
마을 출발 -> 스테이지1(5라운드) -> [귀환 or 상승] -> 스테이지2 ... -> 스테이지5
   -> 보스방 앞 [도전 or 마을로 돌아가기]
귀환 시: 레벨/장비 유지, 돈으로 장비 강화 후 다시 스테이지1부터
죽음 시: 장비, 돈, 레벨 전부 초기화
```

## 제안 (기획자 확인 전)
- 한 라운드는 약 15~25초로 잡아 스테이지 1~2분을 맞춤
- 앱을 닫아도 진행 상태가 저장되게 하되, 스테이지 도중 이탈은 "그 스테이지를 처음부터 다시"로 처리
- 귀환 시 돈 정산 화면과 장비 강화 화면을 한 화면에서 끝내 짧은 호흡 유지
- 스테이지가 깊을수록(1->5) 돈, 보물 방 확률, 적 강도가 함께 올라가 "더 가면 이득이지만 위험" 구조를 만듦
- 보스 도전은 "지금 장비로 이길 수 있는지" 판단하는 게임이 되도록, 도전 전에 예상 난이도 힌트를 보여 줌
- 죽었을 때 "무엇 때문에 졌는지"(공격 부족, 체력 부족 등)를 간단히 보여 줘서 플레이어의 지식이 쌓이게 함

## 미결정 (임시값 사용, 하드코딩 금지)
- 동료 스탯 수치, 영입 확률, 동료 수 제한, 동료 영혼 칸 수, 죽은 동료의 영혼 처리, 경험치 분배
- 직업별 건물과 장비 강화 건물의 업그레이드 항목, 장비 상점의 판매 목록과 가격
- 직업별 수치, (추후 추가) 마법사의 스탯 성향과 등장 확률, 마탑의 마법 종류와 영혼 스킬과의 관계와 기본 무기/고유 능력, 직업과 장비/영혼의 관계
- 육감의 감지 수치 기준, 피로/공포 상태이상의 구체적 내용, 스탯별 수치와 성장 곡선, 장비/레벨/영혼이 스탯에 기여하는 방식
- 영혼 칸이 늘어나는 레벨 구간, 액티브 스킬의 종류(발동은 자동)
- 이벤트의 종류와 구성 (보물 방이 이벤트의 한 종류인지 별개인지 포함)
- 보물 방 등장 확률, 이벤트별 확률과 보상
- 희귀도 단계 수와 이름
- 장비 강화 방식과 비용 곡선
- 필요 경험치 곡선과 레벨 상한
- 여관의 회복 비용과 회복량
- 챕터 클리어 후 보상, 다음 챕터 해금 방식
- 보스의 종류와 수, 죽은 뒤 이야기상의 처리(주인공이 죽으면 어떻게 되는지)
